Лабораторная работа 1

Переходный процесс с обратной связью по мощности и системой регулирования

Теоретическая часть. Интерактивная модель и графики будут добавлены отдельным разделом.

Цель работы

Исследовать динамику ядерного реактора при переводе мощности с одного уровня на другой с учётом обратной связи по мощности и автоматической системы регулирования.

  1. Реализовать численное интегрирование линеаризованной системы точечной кинетики с одной группой запаздывающих нейтронов.
  2. Исследовать четыре комбинации обратных связей.
  3. Оценить влияние коэффициентов реактивности, усиления и инерционности регулятора.
  4. Построить зависимости отклонения мощности, реактивности и переменных регулятора.

1. Уравнения динамики

Рассматривается точечная модель кинетики реактора с одной эффективной группой запаздывающих нейтронов, дополненная уравнением системы регулирования и линейной обратной связью по мощности.

\begin{cases} \dfrac{dn}{dt} = \dfrac{\rho_{cm} + \alpha_w n - \beta}{l}\, n + \lambda c,\\[8pt] \dfrac{dc}{dt} = \dfrac{\beta}{l}\, n - \lambda c,\\[8pt] \tau_p \dfrac{d^2 \rho_{cm}}{dt^2} + \dfrac{d\rho_{cm}}{dt} = -x_0 y. \end{cases}
  • n — плотность нейтронов, пропорциональная мощности;
  • c — концентрация предшественников запаздывающих нейтронов;
  • rho_cm — реактивность, вносимая системой регулирования;
  • alpha_w — коэффициент реактивности по мощности;
  • beta — доля запаздывающих нейтронов;
  • l — время жизни мгновенных нейтронов;
  • lambda — постоянная распада предшественников;
  • tau_p — постоянная времени регулятора.

2. Линеаризация

Введём отклонения от стационарного состояния: \delta n = n - n_{уст} и \delta c = c - c_{уст}. После отбрасывания членов второго порядка малости:

\begin{cases} \dfrac{d\,\delta n}{dt} = \dfrac{\rho_{cm} + (\alpha_w n_{уст} - \beta)}{l}\,\delta n + \lambda\,\delta c,\\[8pt] \dfrac{d\,\delta c}{dt} = \dfrac{\beta}{l}\,\delta n - \lambda\,\delta c. \end{cases}

3. Относительные переменные

Переходим к \delta w = \delta n / n_{уст} и \widetilde{\delta c} = \delta c / c_{уст}, где c_{уст} = \beta n_{уст}/(\lambda l):

\begin{cases} \dfrac{d\,\delta w}{dt} = \dfrac{A\,\rho_{cm} + (B\,\alpha_w n_{уст} - \beta)\,\delta w}{l} + \dfrac{\beta}{l}\,\widetilde{\delta c},\\[8pt] \dfrac{d\,\widetilde{\delta c}}{dt} = \lambda(\delta w - \widetilde{\delta c}),\\[8pt] \dfrac{d\rho_{cm}}{dt} = Z,\\[8pt] \dfrac{dZ}{dt} = -\dfrac{Z}{\tau_p} - \dfrac{x_0}{\tau_p}\,\delta w. \end{cases}

4. Начальные условия и стационарное состояние

При t = 0 реактор работает на уровне n_0. Введём \alpha = n_0/n_{уст}:

\delta w(0) = 1 - \alpha,\qquad \widetilde{\delta c}(0) = 1 - \alpha,\qquad \rho_{cm}(0)=0,\qquad Z(0)=0.

При n_{уст} < 1 мощность снижается, при n_{уст} > 1 — растёт. В стационарном состоянии:

\delta w_{ст}=0,\qquad \widetilde{\delta c}_{ст}=0,\qquad Z_{ст}=0,\qquad \rho_{cm,ст}=0.

6. Метод решения

Вектор состояния имеет вид:

\mathbf y = (\delta w,\ \widetilde{\delta c},\ \rho_{cm},\ Z)^T.

Интегрирование выполняется классическим методом Рунге–Кутты 4-го порядка:

\mathbf y_{n+1} = \mathbf y_n + \dfrac{h}{6}(\mathbf k_1 + 2\mathbf k_2 + 2\mathbf k_3 + \mathbf k_4).

Для параметров из работы быстрая составляющая имеет оценку \lambda_{max} \approx -20.1\,\text{с}^{-1}. Шаг h=10^{-4}\,\text{с} выбран существенно меньше времени жизни мгновенных нейтронов.
