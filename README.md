# MMPHP labs

Фронтенд для расчётов математических моделей ядерных реакторов.

## Быстрый старт

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Каталог работ: [http://localhost:3000/](http://localhost:3000/).

| Работа | Страница |
| --- | --- |
| 1. Обратная связь по температуре топлива | [lab01](http://localhost:3000/dist/7_sem/lab01/) |
| 2. Обратная связь по мощности и регулирование | [lab02](http://localhost:3000/dist/7_sem/lab02/) |

Сборка страниц и состав автономного архива описаны в [docs/labs.md](docs/labs.md).
