# MMPHP labs

Фронтенд для физических рассчетов математических моделей ядерных реакторов.

## Быстрый старт

Требуется Node.js 20 или новее.

```bash
npm install
npm run build:all
```

После сборки откройте `index.html` через любой локальный HTTP-сервер. Для режима разработки можно использовать:

```bash
npm run dev
```

Страница отображает стартовое сообщение, которое устанавливается из `src/main.ts`.

## Автономная лабораторная

Теория первой лабораторной находится в `7_sem/lab01/index.html`. Оформление — в корневом `styles.css`, расчёт переходного процесса — в `src/lab01/`. Формулы записаны в LaTeX и отображаются локальным KaTeX, поэтому результат не зависит от CDN и интернета.

Собрать автономную версию лабораторной:

```bash
npm run build:lab01
```

После этого каталог `dist/7_sem/lab01/` можно целиком упаковать в zip-архив. В архиве должны находиться `index.html`, `styles.css`, каталог `js/`, `katex.min.js`, `katex.min.css` и каталог `fonts/`. Такой архив можно распаковать и открыть через локальный HTTP-сервер или разместить на любом статическом хостинге.

Для проверки локально из корня проекта:

```bash
npm run dev
```

Затем откройте `http://localhost:3000/dist/7_sem/lab01/`.

## Зависимости

- nodejs, ts
- какой-нибудь latex для визуализации формул
- мат движок для рассчетов формул
